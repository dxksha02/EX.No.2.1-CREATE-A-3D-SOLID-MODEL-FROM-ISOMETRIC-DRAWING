# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

1.First, open Autodesk Fusion 360 and create a new design by selecting the New Design option. Make sure that the Design workspace is active before starting the modelling 	   process. 


<img width="530" height="263" alt="Screenshot 2026-11-15 154946" src="https://github.com/user-attachments/assets/97bb420a-71cd-40c8-adeb-4f43450f5cdb" />



2.Select the Sketch option from the toolbar and choose the Front (XZ) plane as the working plane. The sketch grid will appear with the origin and reference axes.


3.Select the Rectangle tool from the Sketch toolbar and choose the Center Rectangle option to create the base profile of the component. Place the cursor at the origin and     enter the dimensions of 100 mm width and 60 mm height using the dimension input boxes.


<img width="850" height="414" alt="Screenshot 2026-11-13 140159" src="https://github.com/user-attachments/assets/a7b27f5d-aff8-4638-b51e-824816ede6b1" />



4.After completing the rectangle, select the Finish Sketch option to close the sketch workspace. Select the Extrude command and choose the rectangular sketch profile. Enter   an extrusion distance of 30 mm to create the main rectangular solid block and confirm the operation.


<img width="385" height="255" alt="Screenshot 2026-11-13 140429" src="https://github.com/user-attachments/assets/c9912dbc-8211-4b6a-90ec-eee627ee7eba" />



5.Next, select the Create Sketch option and choose the front face of the rectangular block as the sketch plane. This face will be used to create the large circular            projection shown in the isometric drawing.


6.Select the Circle tool and choose the Center Diameter Circle option. Position the centre of the circle at the required location on the front face. Enter the circle          diameter as 100 mm and complete the circle.


7.Select the Finish Sketch option to complete the circular profile. Then select the Extrude command, choose the circular sketch region and enter an extrusion distance of      20 mm. Confirm the operation to create the cylindrical projection on the front face of the component.


<img width="838" height="381" alt="Screenshot 2026-11-13 141913" src="https://github.com/user-attachments/assets/328e1b3c-047f-47ba-9ac9-4c630fcf5bf6" />



8.Select Create Sketch and choose the top face of the rectangular block to draw the remaining features.

9.Use the Line and Rectangle tools to draw the required shapes on the top surface according to the given drawing.


10.Make the necessary changes to the sketch and ensure that all the lines are properly connected.


11.Click Finish Sketch and use the Extrude tool to raise the required profiles. Enter the heights given in the drawing.



<img width="385" height="255" alt="Screenshot 2026-11-13 140429" src="https://github.com/user-attachments/assets/6d4bb4aa-ec4a-4c58-99aa-5d5605a52e81" />



12.To create the square raised feature, select the top face, draw a square using the Rectangle tool and extrude it.

13.To create the circular raised feature, draw a circle using the Center Diameter Circle tool and extrude it to the required height.

14.Draw the inclined portion using the Line tool and use Extrude to create the raised feature.

15.After completing all the features, inspect the model carefully and check whether the arrangement of the rectangular block, circular projection, square feature,              cylindrical feature and inclined portion matches the given isometric drawing.

16.Finally, use the ViewCube to change the viewing direction to the Isometric view. Save the completed 3D solid model using the Save option with the appropriate experiment name.
